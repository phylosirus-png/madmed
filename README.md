## ✨ Fonctionnalités

- **Patients** — dossiers complets (antécédents, allergies, contact d'urgence, pièce d'identité, photo), historique de toutes les consultations
- **Agenda** — rendez-vous par praticien, code couleur, import/export Excel
- **Consultations** — motif, signes vitaux, dépistages, suivi gynéco-obstétrique
- **Ordonnances & Certificats médicaux** — génération PDF professionnelle, prêts à imprimer
- **Facturation** — factures et proformas, suivi des paiements, alertes de factures en retard
- **Caisse** — entrées/sorties, journal comptable avec solde courant
- **Stock** — matériel, consommables, médicaments ; alertes de stock bas et de péremption ; vente directe aux patients reliée automatiquement à la caisse
- **Rapports** — rapport d'activité médicale (statistiques par sexe/âge, motifs fréquents) et journal de bord (trace chronologique complète de l'activité du cabinet)
- **Multi-praticiens** — médecins, infirmiers(ères), sages-femmes, secrétaires, chacun avec son propre accès
- **Toutes les données restent sur votre ordinateur** — aucune information patient n'est envoyée sur Internet

## ⬇️ Installation

1. Allez dans l'onglet **[Releases](../../releases)** de ce dépôt
2. Téléchargez le fichier `Madmed Setup.exe` de la dernière version
3. Lancez l'installateur et suivez les étapes (une page de licence à accepter apparaît — c'est normal)

> ⚠️ Windows peut afficher un avertissement **"Windows a protégé votre ordinateur"** car l'installateur n'est pas encore signé numériquement. Cliquez sur **"Informations complémentaires"** puis **"Exécuter quand même"** — Madmed ne contient aucun logiciel malveillant, cet avertissement concerne simplement les nouveaux éditeurs de logiciels.

**Configuration requise :** Windows 10 ou plus récent.

Madmed est utilisable **gratuitement pendant 15 jours**, sans aucune limitation de fonctionnalités.

Passé ce délai, la poursuite de l'utilisation nécessite un **code d'activation**, à obtenir directement auprès de l'éditeur :

1. Depuis l'écran d'activation du logiciel, cliquez sur le bouton WhatsApp ou e-mail (préremplis automatiquement avec l'identifiant de votre ordinateur)
2. Vous recevez un code d'activation valable **définitivement sur cet ordinateur**

## 🔒 Confidentialité

Toutes les données saisies dans Madmed (patients, consultations, factures...) sont stockées **localement** dans une base de données sur l'ordinateur du cabinet. Aucune donnée n'est transmise à l'éditeur ni à un serveur externe. La politique de confidentialité complète est consultable directement depuis le logiciel (écran de connexion ou menu principal).
